# FinanceAI

## 📊 Sobre o projeto

O **FinanceAI** é um projeto de aplicação para controle financeiro pessoal, desenvolvido com o objetivo de facilitar o registro e a organização de gastos a partir de comprovantes e notas fiscais.

A proposta é utilizar inteligência artificial para analisar imagens de comprovantes, identificar informações relevantes e organizar os gastos automaticamente.

---

## 🎯 Objetivo

Criar uma ferramenta simples e intuitiva capaz de:

* 📸 Receber fotos de comprovantes e notas fiscais.
* 🤖 Utilizar inteligência artificial para analisar as imagens.
* 🏪 Identificar o estabelecimento.
* 📅 Identificar a data da compra.
* 💰 Identificar o valor total da compra.
* 🛒 Identificar os produtos presentes na nota.
* 📋 Organizar o histórico de gastos.
* 👤 Separar os dados de diferentes usuários.

---

## 🚀 Funcionalidades atuais

* ✅ Sistema de login e cadastro por usuário.
* ✅ Armazenamento dos gastos no navegador.
* ✅ Captura de imagem utilizando a câmera do dispositivo.
* ✅ Seleção de imagem pela galeria.
* ✅ Análise de notas fiscais utilizando inteligência artificial.
* ✅ Identificação de estabelecimento, data, valor e categoria.
* ✅ Extração dos produtos encontrados na nota.
* ✅ Exibição do histórico de comprovantes.
* ✅ Cálculo do total de gastos registrados.
* ✅ Projeto versionado com Git e GitHub.
